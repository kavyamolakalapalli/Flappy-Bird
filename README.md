# Flappy-Bird
The Flappy-Bird is a game in which we have a bird and pillars, where there is a small gap between them.
In this we consider a red dot to represent the bird.
The **goal** is to control the bird (which is notoriously difficult) and navigate through the spaces between the pillars. The further you go, the more points you earn. For each pillar you pass through, you earn an additional point.
At last you can see your highscore on the screen for all the plays.
